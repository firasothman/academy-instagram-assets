# academy-instagram-assets

استضافة عامة مؤقتة لصور منشورات إنستغرام.

ميتا لا تستقبل الصور كبايتات — تسحبها من رابط HTTPS عام. هذا المستودع هو ذلك الرابط.

```
posts/story/<تاريخ>-<slug>-<بصمة>/image.png
posts/single/<تاريخ>-<slug>-<بصمة>/image.png
posts/carousel/<تاريخ>-<slug>-<بصمة>/01.png … 05.png
```

الصور تُحذف تلقائياً بعد تأكيد النشر: ميتا تنسخ الصورة وقت إنشاء الحاوية،
فلا حاجة لبقاء الرابط بعدها.

أسماء الملفات لا تتكرر أبداً — تحمل تاريخاً وبصمة محتوى، لأن CDN
يخزّن مؤقتاً وقد يسلّم صورة قديمة لو أُعيد استخدام اسم.

المحرّك في `firasothman/academy-instagram-secrets`.
